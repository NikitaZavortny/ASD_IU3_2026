# Расчёт асимптотики: задача 58. Заполнение матрицы змейкой

n — число строк матрицы, m — число столбцов.
Операции с int считаем O(1).
Оценки для матрицы в таблице предполагают n, m ≥ 1.
Память входных данных отделена от дополнительной памяти алгоритма.

| Задача | Время | Дополнительная память |
| --- | --- | --- |
| 58. Змейка | Θ(nm) | Θ(nm) для возвращаемой матрицы, Θ(1) сверх неё |

## Обоснование

Два цикла записывают ровно nm значений, направление выбирается по чётности строки.
T(n, m) = c₀ + c₁n + c₂nm = Θ(nm). Счётчик и индексы занимают Θ(1).
Возвращаемая матрица занимает Θ(nm) для n, m ≥ 1.
В Java есть также n ссылок и n объектов строк: с нулевыми размерами точная оценка
времени и памяти результата — Θ(1 + n + nm).
