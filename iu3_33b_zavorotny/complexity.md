# Расчёт асимптотики

n — длина массива или число строк матрицы, m — число столбцов.
Операции с int считаем O(1). Оценки для матриц в таблице предполагают n, m ≥ 1.
Память входных данных отделена от дополнительной памяти алгоритма.

| Задача | Время | Дополнительная память |
| --- | --- | --- |
| 1. Минимум и максимум | Θ(n) | Θ(1), включая результат из двух чисел |
| 15. Пузырьковая сортировка | лучший случай Θ(n), средний и худший Θ(n²) | Θ(1), сортировка на месте |
| 57. Спираль | Θ(nm) | Θ(nm) для возвращаемого массива, Θ(1) сверх него |
| 58. Змейка | Θ(nm) | Θ(nm) для возвращаемой матрицы, Θ(1) сверх неё |
| 59. Определитель 3 × 3 | Θ(1) | Θ(1) |

## Задача 1

Первый элемент задаёт начальные минимум и максимум. Остальные n − 1 элементов
проверяются по одному разу, по два сравнения на элемент: T(n) = c₀ + c₁(n − 1) = Θ(n).
Новый минимум и максимум заменяют прежние значения. Количество переменных постоянно,
результат содержит два int: дополнительная память Θ(1).
Консольная программа хранит входной массив, поэтому её полная память Θ(n).
Ограничение 1 < n < 100000 проверяется и для API, и при чтении размера.

## Задача 15

После прохода наибольший элемент оставшегося префикса находится в его конце.
Следующий проход короче на одно сравнение. В худшем случае сравнения выполняются
(n − 1) + (n − 2) + ... + 1 = n(n − 1)/2 раз, то есть Θ(n²).
Если за первый проход не было обменов, массив уже отсортирован: выполняется
n − 1 сравнений и происходит досрочный выход. Лучшее время Θ(n) при n ≥ 2.
Для пустого массива и одного элемента время Θ(1).

Средняя оценка Θ(n²) относится к равновероятным перестановкам различных элементов.
Среднее число инверсий такой перестановки равно n(n − 1)/4. Каждый обмен соседней
неупорядоченной пары уменьшает число инверсий ровно на одну. Поэтому среднее число
обменов уже даёт нижнюю границу Ω(n²), а верхняя граница сравнений — O(n²).

Общее число обменов равно исходному числу строгих инверсий, максимум n(n − 1)/2.
Счётчик имеет тип long, поскольку этого количества может не вместить int.
Новый массив для сортировки не создаётся: дополнительная память Θ(1), полная Θ(n).

## Задача 57

Четыре границы ограничивают ещё не обойдённую часть матрицы. После обхода слоя
верхняя и левая границы увеличиваются, нижняя и правая уменьшаются.
Углы не посещаются повторно. Если осталась одна строка или один столбец,
проверки в appendLayer исключают повторный обход противоположной стороны.

Каждый элемент добавляется в результат ровно один раз: Θ(nm).
Проверка прямоугольности занимает Θ(n) и не меняет итоговую оценку.
Результат int[nm] занимает Θ(nm), границы и индексы — Θ(1).
Входная матрица не меняется. Полная память программы — Θ(nm) для непустой матрицы.
С учётом нулевых размеров время равно Θ(1 + n + nm), память результата — Θ(1 + nm).

## Задача 58

Два цикла записывают ровно nm значений, направление выбирается по чётности строки.
T(n, m) = c₀ + c₁n + c₂nm = Θ(nm). Счётчик и индексы занимают Θ(1).
Возвращаемая матрица занимает Θ(nm) для n, m ≥ 1.
В Java есть также n ссылок и n объектов строк: с нулевыми размерами точная оценка
времени и памяти результата — Θ(1 + n + nm).

## Задача 59

Матрица всегда содержит девять int. Разложение по первой строке вычисляет три
минора, три произведения и два сложения/вычитания: число операций постоянно.
Размер каждого числа ограничен разрядностью int и фиксированным размером матрицы.
Поэтому время и память Θ(1), несмотря на применение BigInteger для результата.

Минора, составленного из двух произведений int, достаточно хранить в long.
Для результата используется BigInteger: произведение трёх int может выйти за long.
Для входных чисел произвольной разрядности потребовалось бы отдельно учитывать
стоимость длинной арифметики; здесь вход ограничен типом int.
