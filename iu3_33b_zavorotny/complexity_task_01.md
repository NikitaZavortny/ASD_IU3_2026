# Расчёт асимптотики: задача 1. Минимум и максимум

n — длина массива.
Операции с int считаем O(1).
Память входных данных отделена от дополнительной памяти алгоритма.

| Задача | Время | Дополнительная память |
| --- | --- | --- |
| 1. Минимум и максимум | Θ(n) | Θ(1), включая результат из двух чисел |

## Обоснование

Первый элемент задаёт начальные минимум и максимум. Остальные n − 1 элементов
проверяются по одному разу, по два сравнения на элемент: T(n) = c₀ + c₁(n − 1) = Θ(n).
Новый минимум и максимум заменяют прежние значения. Количество переменных постоянно,
результат содержит два int: дополнительная память Θ(1).
Консольная программа хранит входной массив, поэтому её полная память Θ(n).
Ограничение 1 < n < 100000 проверяется и для API, и при чтении размера.
