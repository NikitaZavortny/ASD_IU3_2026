# Отчёт: задача 58. Заполнение матрицы змейкой

ФИО: Заворотний Н. И.  
Группа: ИУ3-33Б  
Номер лабораторной: 1

## Постановка задачи

Ввод: размеры `n m`.
Вывод: матрица `n × m` с числами от 1 до `n · m`, заполненная змейкой по строкам.

## Структура

Решение оформлено одним самостоятельным классом `SnakeMatrix` в файле `SnakeMatrix.java`.
Ввод, вывод, проверки и алгоритм находятся внутри этого класса.
Для проверки используется отдельный класс `SnakeMatrixTest` в файле `SnakeMatrixTest.java`.

## Идея решения

Создаём `int[n][m]` и последовательно записываем числа от 1 до `n · m`.
Первая строка заполняется слева направо, вторая справа налево и так далее.

В коде строки нумеруются с нуля: для чётного индекса направление слева направо,
для нечётного — справа налево. Счётчик увеличивается после записи каждой клетки.

Результат хранится в двумерном массиве. Дополнительные структуры данных не нужны.
Отрицательные размеры и число элементов больше `Integer.MAX_VALUE` отклоняются.
Нулевые размеры допускаются.

## Анализ асимптотики

Внешний цикл имеет `n` итераций, внутренний — `m`. На каждую клетку приходится
постоянное число операций, поэтому при `n, m ≥ 1` время — `Θ(nm)`.

Память возвращаемой матрицы — `Θ(nm)`. Счётчик и индексы занимают `Θ(1)`
дополнительной памяти сверх результата. Отдельный разворот строк не выполняется.

Java-матрица содержит также `n` ссылок на строки и `n` объектов строк.
Поэтому с учётом нулевых размеров точная оценка времени и памяти результата —
`Θ(1 + n + nm)`. При `m = 0` создаются `n` пустых строк, при `n = 0` строк нет.

## Ручные тесты

| Вход | Ожидаемый результат | Что проверяет |
| --- | --- | --- |
| n=3, m=4 | 1 2 3 4; 8 7 6 5; 9 10 11 12 | Чередование направления |
| n=1, m=3 | 1 2 3 | Одна строка |
| n=3, m=1 | 1; 2; 3 | Один столбец |
| n=1, m=1 | 1 | Одна клетка |
| n=0, m=4 | Нет строк | Нулевое число строк |
| n=−1, m=2 | IllegalArgumentException | Отрицательный размер |

Точка с запятой в таблице разделяет строки матрицы или части результата.

## Автоматическая проверка

Основные тесты JUnit 5:

- `shouldAlternateDirectionForRectangularMatrix` — чередование направления в прямоугольной матрице.
- `shouldFillSingleRow` — заполнение одной строки.
- `shouldFillSingleColumn` — заполнение одного столбца.
- `shouldSupportZeroRows` — нулевое число строк.
- `shouldRejectValuesBeyondIntegerRangeBeforeAllocation` — защита от переполнения значений.
- `shouldPrintSnakeWithoutTrailingSpaces` — формат вывода без лишних пробелов.

Также проверяются одна клетка, нулевое число столбцов и отрицательные размеры.
