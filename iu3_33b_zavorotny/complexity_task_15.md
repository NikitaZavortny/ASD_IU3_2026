# Расчёт асимптотики: задача 15. Пузырьковая сортировка

n — длина массива.
Операции с int считаем O(1).
Память входных данных отделена от дополнительной памяти алгоритма.

| Задача | Время | Дополнительная память |
| --- | --- | --- |
| 15. Пузырьковая сортировка | лучший случай Θ(n), средний и худший Θ(n²) | Θ(1), сортировка на месте |

## Обоснование

После прохода наибольший элемент оставшегося префикса находится в его конце.
Следующий проход короче на одно сравнение. В худшем случае сравнения выполняются
(n − 1) + (n − 2) + ... + 1 = n(n − 1)/2 раз, то есть Θ(n²).
Если за первый проход не было обменов, массив уже отсортирован: выполняется
n − 1 сравнений и происходит досрочный выход. Лучшее время Θ(n) при n ≥ 2.
Для пустого массива и одного элемента время Θ(1).

Средняя оценка Θ(n²) относится к равновероятным перестановкам различных элементов.
Среднее число инверсий такой перестановки равно n(n − 1)/4. Каждый обмен соседней
неупорядоченной пары уменьшает число инверсий ровно на одну. Поэтому среднее число
обменов уже даёт нижнюю границу Ω(n²), а верхняя граница сравнений — O(n²).

Общее число обменов равно исходному числу строгих инверсий, максимум n(n − 1)/2.
Счётчик имеет тип long, поскольку этого количества может не вместить int.
Новый массив для сортировки не создаётся: дополнительная память Θ(1), полная Θ(n).
