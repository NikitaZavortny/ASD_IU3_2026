# Отчёт: задача 1. Максимум и минимум

ФИО: Заворотний Н. И.  
Группа: ИУ3-33Б  
Номер лабораторной: 1

## Постановка задачи

Ввод: число `n`, затем `n` целых чисел типа `int`, где `1 < n < 100000`.
Вывод: минимум и максимум через пробел.

## Структура

Решение оформлено одним самостоятельным классом `MinMax` в файле `MinMax.java`.
Ввод, вывод, проверки и алгоритм находятся внутри этого класса.
Для проверки используется отдельный класс `MinMaxTest` в файле `MinMaxTest.java`.

## Идея решения

Первый элемент принимается за начальные минимум и максимум. Затем за один проход
сравниваем каждый следующий элемент с текущими экстремумами и при необходимости
обновляем их. Начальные значения берутся из массива, поэтому алгоритм правильно
работает и с полностью отрицательными данными.

Вход хранится в `int[]`, результат — в массиве из двух чисел: сначала минимум,
затем максимум. Исходный массив не изменяется. Проверяется ограничение `1 < n < 100000`.

## Анализ асимптотики

После инициализации выполняются `n − 1` итераций, в каждой — два сравнения:
`T(n) = c₀ + c₁(n − 1) = Θ(n)`.

Для экстремумов и индекса используется постоянное количество переменных.
Результат содержит ровно два числа, поэтому дополнительная память — `Θ(1)`.
Полная память консольной программы с учётом входного массива — `Θ(n)`.

## Ручные тесты

| Вход | Ожидаемый результат | Что проверяет |
| --- | --- | --- |
| n=4; 3 −5 9 0 | −5 9 | Экстремумы внутри массива |
| n=2; 7 2 | 2 7 | Минимальная допустимая длина |
| n=3; −8 −2 −10 | −10 −2 | Все элементы отрицательные |
| n=3; 4 4 4 | 4 4 | Все элементы равны |
| n=1 | IllegalArgumentException | Нижняя граница исключена |
| n=100000 | IllegalArgumentException | Верхняя граница исключена |


## Автоматическая проверка

Основные тесты JUnit 5:

- `shouldFindMixedExtremes` — поиск обоих экстремумов.
- `shouldHandleNegativeValues` — работа с отрицательными числами.
- `shouldAcceptMaximumAllowedLength` — массив из 99 999 элементов.
- `shouldPreserveInput` — сохранение исходного массива.
- `shouldRejectSingleElement` — отклонение массива длины 1.
- `shouldRejectUpperExclusiveBound` — отклонение длины 100 000.

Также проверяются `null`, пустой массив, границы `int`, одинаковые элементы и формат вывода.
