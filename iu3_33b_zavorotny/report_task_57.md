# Отчёт: задача 57. Спиральный обход матрицы

ФИО: Заворотний Н. И.  
Группа: ИУ3-33Б  
Номер лабораторной: 1

## Постановка задачи

Ввод: размеры `n m`, затем матрица из `n · m` целых чисел.
Вывод: элементы по спирали от левого верхнего угла по часовой стрелке, одной строкой.

## Структура

Решение оформлено одним самостоятельным классом `SpiralTraversal` в файле `SpiralTraversal.java`.
Ввод, вывод, проверки и алгоритм находятся внутри этого класса.
Для проверки используется отдельный класс `SpiralTraversalTest` в файле `SpiralTraversalTest.java`.

## Идея решения

Четыре границы задают необойдённую часть матрицы: верхнюю, нижнюю, левую и правую.
Для каждого слоя обходим верхнюю сторону слева направо, правую сверху вниз,
нижнюю справа налево и левую снизу вверх. Затем сдвигаем границы внутрь.

Углы не добавляются повторно. Если осталась одна строка или один столбец,
проверки границ исключают повторный обход совпадающих сторон.

Вход хранится в `int[][]`, результат — в `int[]`. Вспомогательные коллекции
не используются, исходная матрица сохраняется. Проверяются прямоугольность,
отсутствие `null`-строк и возможность разместить результат в массиве.

## Анализ асимптотики

Каждый из `n · m` элементов добавляется в результат ровно один раз.
Проверка прямоугольности занимает `Θ(n)`. При `n, m ≥ 1` итоговое время — `Θ(nm)`.

Результат содержит `n · m` чисел, поэтому его память — `Θ(nm)`.
Границы и индексы занимают `Θ(1)` дополнительной памяти сверх результата.
Полная память программы с входной матрицей — `Θ(nm)` при положительных размерах.

С учётом нулевых размеров время равно `Θ(1 + n + nm)`, память результата —
`Θ(1 + nm)`. Для входной Java-матрицы учитываются также `n` ссылок на строки.

## Ручные тесты

| Вход | Ожидаемый результат | Что проверяет |
| --- | --- | --- |
| 2 × 3: 1 2 3; 4 5 6 | 1 2 3 6 5 4 | Прямоугольная матрица |
| 3 × 3: 1 2 3; 4 5 6; 7 8 9 | 1 2 3 6 9 8 7 4 5 | Несколько слоёв и центр |
| 1 × 3: 1 2 3 | 1 2 3 | Одна строка без повторений |
| 3 × 1: 1; 2; 3 | 1 2 3 | Один столбец без повторений |
| 1 × 1: 7 | 7 | Один элемент |
| n=0, m=3 | Пустая строка | Пустая матрица |

Точка с запятой в таблице разделяет строки матрицы или части результата.

## Автоматическая проверка

Основные тесты JUnit 5:

- `shouldTraverseSquare` — квадратная матрица с центральным элементом.
- `shouldTraverseWideMatrix` — матрица с большим числом столбцов.
- `shouldTraverseTallMatrix` — матрица с большим числом строк.
- `shouldTraverseSingleRowOnce` — одна строка без повторений.
- `shouldTraverseSingleColumnOnce` — один столбец без повторений.
- `shouldPreserveInput` — сохранение исходной матрицы.

Также проверяются нулевые размеры, повторяющиеся и отрицательные значения, некорректная структура матрицы, слишком большой результат и консольный вывод.
