# Отчёт: задача 59. Определитель матрицы 3×3

ФИО: Заворотний Н. И.  
Группа: ИУ3-33Б  
Номер лабораторной: 1

## Постановка задачи

Ввод: девять целых чисел типа `int`, образующих матрицу `3 × 3`.
Вывод: точное значение определителя.

## Структура

Решение оформлено одним самостоятельным классом `Determinant3x3` в файле `Determinant3x3.java`.
Ввод, вывод, проверки и алгоритм находятся внутри этого класса.
Для проверки используется отдельный класс `Determinant3x3Test` в файле `Determinant3x3Test.java`.

## Идея решения

Используем разложение определителя по первой строке:

`det A = a₀₀(a₁₁a₂₂ − a₁₂a₂₁) − a₀₁(a₁₀a₂₂ − a₁₂a₂₀) + a₀₂(a₁₀a₂₁ − a₁₁a₂₀)`.

Сначала вычисляем три минора, затем умножаем их на элементы первой строки
и складываем с нужными знаками. Вход хранится в `int[3][3]`.

Перед умножением внутри миноров один из операндов приводится к `long`.
Миноры из двух произведений `int` помещаются в `long`, но итоговый определитель
может выйти за его диапазон. Поэтому итоговые произведения и результат
вычисляются с помощью `BigInteger` из стандартной библиотеки Java.

Проверяются размер `3 × 3`, отсутствие `null` и корректность строк.
Исходная матрица не изменяется.

## Анализ асимптотики

Размер матрицы фиксирован: три строки и три столбца. Алгоритм вычисляет три
минора, три итоговых произведения и два сложения/вычитания. Проверка размера
также выполняет постоянное число действий. Время — `Θ(1)`.

Число переменных и размер входной матрицы постоянны, поэтому память — `Θ(1)`.
Элементы ограничены типом `int`, а степень выражения фиксирована. Следовательно,
разрядность результата тоже ограничена константой и применение `BigInteger`
не меняет оценку. Для целых произвольной разрядности потребовалась бы другая модель.

## Ручные тесты

| Вход | Ожидаемый результат | Что проверяет |

Точка с запятой в таблице разделяет строки матрицы или части результата.

## Автоматическая проверка

Основные тесты JUnit 5:

- `shouldCalculateGeneralMatrix` — вычисление общего определителя.
- `shouldReturnZeroForDependentRows` — нулевой определитель при зависимых строках.
- `shouldReturnNegativeDeterminantAfterRowSwap` — знак после перестановки строк.
- `shouldAvoidOverflowForExtremeDiagonalValues` — большие диагональные значения.
- `shouldSubtractLargeProductsWithoutOverflow` — корректное вычитание больших произведений.
- `shouldRejectWrongRowCount` — отклонение неверного размера.

Также проверяются единичная матрица, число столбцов, пустая матрица, null-строка, null-матрица и консольный вывод.
